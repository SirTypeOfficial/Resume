## 🇮🇷 فارسی

### مسئله و چالش معماری

قبل از نیکان شغل تولید نداشتم. مسیر از دوره‌های سازمان مدیریت صنعتی واحد جنوب شروع شد، بعد دو سال خدمت سربازی، بعد اولین نقش .NET. ASP.NET Core را قبل از نیکان با self-study جمع کردم تا همان استک را در مصاحبه و کار داشته باشم.

### راهکار و Trade-off

ترتیب دوره‌ها:

1. برنامه‌نویسی شی‌گرا (OOP) و مبانی C#، سال ۱۳۹۲، سازمان مدیریت صنعتی واحد جنوب. گواهینامه: شهریور ۱۳۹۲ / August 2013.
2. توسعه وب با PHP و فریم‌ورک CodeIgniter، سال ۱۳۹۳، همان مؤسسه.
3. توسعه اپلیکیشن موبایل با Xamarin.Android، سال ۱۳۹۵، همان مؤسسه. گواهینامه: بهمن ۱۳۹۵ / January 2017.
4. دو سال خدمت سربازی.
5. قبل از ورود به نیکان (تیر ۱۳۹۷): دوره بیش از ۱۲۰ ساعته ASP.NET Core آرزو ابراهیمی به‌صورت self-study، و کتاب‌های MVC 5.
6. دوره حرفه‌ای MVC و ASP.NET Core، سال ۱۳۹۸، دانشگاه آزاد اسلامی. گواهینامه‌های روی فایل: بهمن ۱۳۹۸ / January 2020 (داخل بازه رستا، بعد از خروج از نیکان در مهر ۱۳۹۸).

### دستاورد (X-Y-Z)

اولین نقش تولید را به‌عنوان توسعه‌دهنده .NET در تیر ۱۳۹۷ در نیکان اکسیر ویستا رایان گرفتم، با سنجش ورود به بک‌اند ASP.NET Core و REST API نوبت‌دهی، از مسیر دوره‌های ۱۳۹۲ تا ۱۳۹۵، دو سال خدمت، و self-study ASP.NET Core / MVC 5.

## 🇬🇧 English

### Problem and architectural challenge

There was no production job before Nikan. The path ran through courses at the Industrial Management Institute, South Unit, then two years of military service, then the first .NET role. ASP.NET Core was learned in self-study before Nikan so that stack was available for the interview and the job.

### Solution and trade-off

Course sequence:

1. Object-oriented programming and C# fundamentals, 1392, IMI South. Certificate dated Shahrivar 1392 / August 2013.
2. Web development with PHP and CodeIgniter, 1393, same institute.
3. Mobile development with Xamarin.Android, 1395, same institute. Certificate dated Bahman 1395 / January 2017.
4. Two years of military service.
5. Before joining Nikan (Tir 1397 / Jul 2018): Arezoo Ebrahimi's ASP.NET Core course (more than 120 hours, self-study) and MVC 5 books.
6. Professional MVC and ASP.NET Core course, 1398, Islamic Azad University. PDFs dated Bahman 1398 / January 2020, which falls during the Rasta tenure, after leaving Nikan in Mehr 1398.

### Achievement (X-Y-Z)

Landed the first production role as a .NET developer at Nikan Exir Vista Rayan in Tir 1397 / Jul 2018, measured by being hired onto an ASP.NET Core backend and a queue-management REST API, by combining the 1392–1395 courses, two years of military service, and ASP.NET Core / MVC 5 self-study.
