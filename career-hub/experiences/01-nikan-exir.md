## 🇮🇷 فارسی

بک‌اند سامانه نوبت‌دهی و رزرو سالن زیبایی را با ASP.NET Core نوشتم تا کلاینت PWA بتواند رزرو، لغو و زمان‌بندی را از طریق REST API انجام دهد.

اسکیمای SQL Server را با Entity Framework طوری بستم که نوبت‌ها، کاربران و بازه‌های زمانی بدون کوئری تکراری ذخیره و خوانده شوند.

با تیم فرانت روی قرارداد API و مدل داده کار کردم تا تبادل بین PWA و سرویس‌های بک‌اند پایدار بماند و خطای همگام‌سازی نوبت کم شود.

## 🇬🇧 English

Built the reservation backend so beauty salons could book, cancel, and schedule appointments from a PWA, by exposing ASP.NET Core REST APIs for the appointment workflow.

Designed SQL Server schemas with Entity Framework so user records, appointment slots, and schedules stayed consistent under read/write load from the booking UI.

Worked with the frontend team on API contracts and payloads so the PWA and backend stayed in sync on appointment state without extra round-trips.
