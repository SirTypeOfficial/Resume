## 🇮🇷 فارسی

### مسئله و چالش معماری

نیکان روی نرم‌افزار حسابداری کار می‌کرد. تیر ۱۳۹۷، بعد از دو سال خدمت سربازی، به‌عنوان توسعه‌دهنده .NET وارد شدم و تا مهر ۱۳۹۸ ماندم. کار من توسعه بک‌اند بود: طراحی و پیاده‌سازی RESTful API با ASP.NET Core برای سامانه مدیریت نوبت‌دهی، و کار با PWA که همان دوره تازه وارد کار تیم شده بود. SQL Server را در همین نقش، روی دادهٔ واقعی، یاد گرفتم. قبل از ورود، دوره بیش از ۱۲۰ ساعته ASP.NET Core آرزو ابراهیمی را self-study دیده بودم و کتاب‌های MVC 5 را خوانده بودم.

### راهکار و Trade-off

REST API را با ASP.NET Core برای جریان نوبت پیاده کردم تا کلاینت PWA بتواند از همان قرارداد JSON برای مدیریت نوبت استفاده کند. داده را روی SQL Server نگه داشتم. تمرکز این نقش بک‌اند، API و کار با همان PWA بود.

### دستاورد (X-Y-Z)

بک‌اند نوبت‌دهی را با REST در اختیار PWA گذاشتم، با سنجش کارکرد API نوبت در بازه تیر ۱۳۹۷ تا مهر ۱۳۹۸، از طریق ASP.NET Core و SQL Server در اولین نقش تولید .NET.

## 🇬🇧 English

### Problem and architectural challenge

Nikan built accounting software. I joined as a .NET developer in Jul 2018 (Tir 1397), after military service, and stayed through Oct 2019 (Mehr 1398). The work was backend: REST APIs on ASP.NET Core for an appointment-queue system, plus a PWA the team had just adopted. I learned SQL Server on the job against production data. Before joining I had completed Arezoo Ebrahimi's ASP.NET Core course (120+ hours, self-study) and had read MVC 5 books.

### Solution and trade-off

I implemented the appointment flow as ASP.NET Core REST endpoints so the PWA could drive queue operations over JSON. Data lived on SQL Server. Scope stayed on backend, API, and that PWA.

### Achievement (X-Y-Z)

Shipped a REST appointment-queue backend for the PWA, in production from Jul 2018 to Oct 2019, on ASP.NET Core and SQL Server in the first production .NET role.
