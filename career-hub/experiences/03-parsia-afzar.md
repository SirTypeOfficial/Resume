## 🇮🇷 فارسی

موتور گردش‌کار (BPMS) را از مونولیت به میکروسرویس‌های مبتنی بر RabbitMQ، CQRS و Domain-Driven Design بازطراحی کردم تا جریان‌های سازمانی جداگانه مقیاس بگیرند و صف پیام، تحمل خطا را بالا ببرد.

تیم توسعه را با بازبینی کد و منتورینگ جلو بردم تا قرارداد بین فرانت Vue.js و APIهای .NET Core یکدست بماند و ادغام ماژول‌ها روی محیط عملیاتی نشکند.

نرم‌افزار عملیاتی برای شرکت‌های توزیع نیروی برق در چند شهر تحویل دادم؛ تمرکز روی دسترسی‌پذیری بالا و کوتاه کردن مسیر پردازش داده در گردش‌کارهای حیاتی شبکه برق بود.

CMS اختصاصی را با ASP.NET Core MVC پیاده کردم تا واحد محتوا بتواند سایت سازمانی را بدون رفت‌وبرگشت به تیم توسعه به‌روز کند.

## 🇬🇧 English

Rebuilt the BPMS workflow engine from a monolith into RabbitMQ-backed microservices with CQRS and Domain-Driven Design so each workflow could scale on its own and message queues absorbed downstream failures.

Led the delivery team with code reviews and mentoring so Vue.js clients and .NET Core APIs stayed on the same contracts and modules integrated without breaking production.

Shipped operational software for electricity-distribution companies in several cities, keeping those services highly available and shortening data paths in grid-critical workflows.

Built an ASP.NET Core MVC CMS so the company could publish and administer its own web content without a developer in the loop for every change.
