## 🇮🇷 فارسی

Git و Azure DevOps را در سازمان راه انداختم تا تیم از گردش‌کار سنتی به برد و اسپرینت Agile/Scrum برسد و انتشار نسخه‌ها قابل ردیابی شود.

تحویل CRM مالی و پلتفرم سرمایه‌گذاری تحت شبکه را از جمع‌آوری نیاز تا انتشار مدیریت کردم و الزامات کسب‌وکار را به نقشه فنی و بک‌لاگ قابل اجرا تبدیل کردم.

API مبتنی بر REST را برای سامانه رزرواسیون PWA با ترافیک بالا طراحی و مستقر کردم تا فرانت Angular بتواند موجودی نوبت و رزرو را هم‌زمان با سرور نگه دارد.

مسیر فرانت را به سمت Angular بردم تا رابط کاربری سامانه با قرارداد API هماهنگ شود و تجربه کاربر در رزرو و پنل مالی یکدست بماند.

## 🇬🇧 English

Moved the team off ad-hoc releases onto Git and Azure DevOps so planning, code review, and deploys ran as Agile/Scrum sprints instead of undocumented hand-offs.

Took a financial CRM and a networked investment platform from requirements to delivery by turning business rules into a technical roadmap and a shippable backlog.

Designed and deployed a REST API for a high-traffic PWA reservation product so the Angular client could keep bookings and inventory in sync with the server.

Directed the frontend toward Angular so the reservation and finance UIs talked to the same API contracts and the interface matched the new backend.
