## 🇮🇷 فارسی

سامانه‌های مدیریت سرویس مدارس را برای شیراز، اصفهان و قزوین با C# و Onion Architecture طراحی و نگهداری کردم تا هر شهر بتواند ناوگان و دانش‌آموز را روی یک هسته مشترک، جداگانه مقیاس بدهد.

اپلیکیشن اندروید «سفیر مهر» را با Kotlin نوشتم تا راننده و کاربر ناوگان، عملیات روز را روی موبایل ببندند نه فقط روی پنل وب.

سیستم پلاک‌خوان خودکار (ALPR) را با Python و بینایی ماشین به محصول وصل کردم تا تشخیص پلاک وارد گردش سرویس مدرسه شود، نه به‌صورت ابزار جدا.

در کار روزمره از IDE مبتنی بر عامل (Cursor) استفاده کردم تا اسپرینت کدنویسی کوتاه‌تر شود و بازبینی تغییرات سریع‌تر انجام شود.

چند MVP قابل اجرا را در اسپرینت‌های یک‌هفته‌ای با .NET 10 و PostgreSQL تحویل دادم تا ایده کسب‌وکار قبل از تعهد معماری بزرگ، روی داده واقعی سنجیده شود.

## 🇬🇧 English

Designed and kept school-service platforms running for Shiraz, Isfahan, and Qazvin on C# and Onion Architecture, so each city could scale fleet and student flows on a shared core.

Shipped Safir Mehr, a Kotlin Android app, so drivers and fleet users could close daily operations on the phone instead of only on the web console.

Built an automatic license-plate recognition path in Python with computer vision so plate reads fed the product, not a side tool.

Used an agent-based IDE (Cursor) in daily work so coding sprints stayed short and diffs were cheaper to review.

Delivered several working MVPs in one-week sprints on .NET 10 and PostgreSQL so business ideas could be tested on real data before a larger architecture commitment.
