## 🇮🇷 فارسی

### مسئله و چالش معماری

از دی ۱۴۰۱ تمرکز را از شغل تمام‌وقت پارسیا به سیستم‌های معاملاتی، اتوماسیون، و تحقیق معماری منتقل کردم. این بازه تا آذر ۱۴۰۳ ادامه داشت. کارفرما تمام‌وقت نداشتم. کار مشتری پاره‌وقت و موردی بود: مشاوره، سایت فروشگاهی، و گردش n8n.

### راهکار و Trade-off

از دی ۱۴۰۱ ربات معامله‌گر با MQL4 و MQL5 نوشتم و ماژول‌ها را بک‌تست گرفتم. روی سیستم‌های مدیریت بودجه، مایندست معاملاتی و مدیریت سرمایه کار کردم. کنار این‌ها Blazor را به‌صورت Blazor Hybrid جلو بردم تا بتوانم با .NET MAUI کلاینت کراس‌پلتفرم بنویسم. برای Blockchain چند نمونهٔ .NET ساختم که smart contract را داخل پروژهٔ دات‌نت پیاده می‌کرد.

در همین بازه Agile، Scrum و DevOps را که از رستا می‌شناختم عمیق‌تر کردم و کار با Git و ابزارهای DevOps را حرفه‌ای‌تر جلو بردم. Docker را یاد گرفتم. تسلط روی معماری را بالا بردم، از جمله Onion Architecture و معماری‌های قدیمی‌تر. Python را مخصوصاً برای سیستم‌های معاملاتی همین دوره قوی‌تر کردم. با Pine Script روی همان مسیر تمرین کردم.

تا آذر ۱۴۰۳ اگر کسب‌وکاری می‌رسید مشاوره می‌دادم، سایت فروشگاهی می‌ساختم، و با n8n پایپ‌لاین اتوماسیون برای همان مشتری‌ها می‌چیدم.

### دستاورد (X-Y-Z)

ربات معامله‌گر را روی MQL4 و MQL5 جلو بردم، با سنجش بک‌تست ماژول‌ها، از طریق نوشتن ربات و ماژول بک‌تست و کار روی مدیریت بودجه، مایندست معاملاتی و مدیریت سرمایه.

پایپ‌لاین اتوماسیون و کار مشتری را تا آذر ۱۴۰۳ نگه داشتم، با سنجش سایت فروشگاهی و گردش n8n برای مشتری‌های پاره‌وقت، از طریق مشاوره و اتوماسیون.

مسیر Blazor Hybrid و .NET MAUI را بالا بردم، با سنجش تمرین کلاینت کراس‌پلتفرم روی همان استک، از طریق کار روی Blazor Hybrid.

اتصال smart contract به .NET را در چند پروژهٔ نمونه ثبت کردم، از طریق پیاده‌سازی قرارداد هوشمند داخل پروژهٔ دات‌نت.

Git، Agile/Scrum و DevOps را نسبت به دورهٔ رستا عمیق‌تر کردم و Docker را وارد گردش تحقیق معماری کردم، از طریق دوره و تمرین همان بازه.

تسلط معماری را بالا بردم، با سنجش استفاده از Onion Architecture و معماری‌های قدیمی‌تر، از طریق مطالعه و تمرین همان الگوها.

Python را روی سیستم‌های معاملاتی جلو بردم، از طریق تمرین هدفمند روی همان سیستم‌ها.

### Problem and architectural challenge

In Jan 2023 (Dey 1401) I shifted focus from the full-time Parsia role to trading systems, automation, and architecture research. That independent stretch ran through Dec 2024 (Azar 1403). There was no full-time employer. Client work stayed part-time: consulting, e-commerce sites, and n8n pipelines.

### Solution and trade-off

From Jan 2023 I wrote trading bots in MQL4 and MQL5 and backtested the modules. I also worked through budget-management systems, trading mindsets, and capital management. Alongside that I pushed Blazor further as Blazor Hybrid so I could build cross-platform clients with .NET MAUI. For blockchain I built a few .NET samples that implemented a smart contract inside a .NET project.

In the same stretch I deepened Agile, Scrum, and DevOps from the Rasta years and used Git and DevOps tools more tightly. I learned Docker. I raised fluency in architectures, including Onion Architecture and older styles. I used Python more seriously on the trading systems from this period, and practiced Pine Script on that same path.

Through Dec 2024, when a business came along I consulted, built e-commerce sites, and used n8n to automate workflows for those clients.

Engineered MQL4 and MQL5 trading bots with module-level backtests and capital-management rules.

Streamlined part-time client delivery through n8n automation pipelines and e-commerce sites.

Raised Blazor Hybrid and .NET MAUI fluency by practicing cross-platform clients on that stack.

Recorded smart-contract wiring in a few .NET sample projects by implementing the contract inside those solutions.

Deepened Git, Agile/Scrum, and DevOps relative to the Rasta period, and added Docker to the architecture toolkit.

Applied Python on the trading systems from this period, with targeted practice on that workload.
