## مخزن Career Hub

این مخزن ویترین عمومی و **خزانه شغلی** است. فایل‌های JSON ریشه (`my-resume-en.json`, `my-resume-fa.json`) منبع اولیه استخراج بودند؛ روایت قابل ویرایش و دوزبانه در `career-hub/` نگه داشته می‌شود.

```text
career-hub/
├── experiences/          # سوابق ۰۱ تا ۰۶ (قدیم → جدید) + لینک مدرک
├── certificates/
│   ├── certificates.md   # جدول و لنگر slug
│   └── assets/           # تصویر / PDF مدارک
├── projects/             # پروژه‌های شاخص (در حال تکمیل)
├── linkedin/             # پیش‌نویس پروفایل لینکدین
└── tailored-resumes/     # رزومه‌های سفارشی ATS
    └── archive/
.cursor/rules/
├── career-engine.mdc
├── experience-manager.mdc
└── career-hub-rule.mdc
```

## تولید رزومه ATS با Cursor

وقتی متن آگهی (JD) را در چت می‌گذارید، ایجنت باید از خزانه استفاده کند — نه از بازنویسی آزاد.

1. آگهی را کامل پیست کنید و زبان خروجی را بگویید (`fa` یا `en`).
2. مهارت `tailor-ats-resume` و قانون `.cursor/rules/career-engine.mdc` اعمال می‌شود.
3. ایجنت سوابق ۰۱–۰۶ و مدارک را می‌خواند، نقش‌های هم‌پوشان با استک JD را بالا می‌آورد، و گلوله‌ها را با فرمول **Google X-Y-Z** می‌نویسد (انجام X، با معیار Y، از طریق Z).
4. خروجی تک‌ستونه ATS است: خلاصه، شایستگی‌ها، تجربه، پروژه‌های شاخص، مدارک — بدون جدول و آیکون داخل خود رزومه.
5. فایل در `career-hub/tailored-resumes/` ذخیره می‌شود؛ نسخه‌های قبلی به `archive/` می‌روند.

**نمونه درخواست:**

```text
از روی این آگهی یک رزومه ATS انگلیسی بساز و در career-hub/tailored-resumes ذخیره کن.

[متن Job Description]
```

واژگان کلیشه‌ای مدل زبانی (spearheaded, delve, testament, game-changer, synergy و معادل‌های توخالی فارسی) در قانون career-engine ممنوع است. فقط واقعیت‌های خزانه را به زبان آگهی برگردانید.
